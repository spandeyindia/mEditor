## Baseline Scope

Ver 2 pre-pilot includes the Ver 1 implementation scaffold plus these additional baseline commitments:

- Project Workspace with major projects, sub-projects, project metadata, project roots, run/build/deploy profiles, and same-window project navigation.
- Project Planner under Tools with portfolio/project planning, Objective -> Milestone -> Task and Scrum Epic -> Story -> Task models, timezone-aware timelines, Excel template import/export, cost tracking, Gantt/progress/risk dashboards, and planner-driven project creation.
- Embedded About Project and Project Help documentation for every mEditor-created project under `.meditor/project/docs`, surfaced from the Help menu and opened in same-window tabs.
- Inbuilt professional IDE features inspired by NetBeans, Eclipse, JDeveloper, VS Code, SQL Developer, SQL Developer Data Modeler, Termius, and FileZilla Client.
- SFTP/SCP transfer manager modeled on site profiles, queues, resume, bookmarks, filters, and directory compare.
- Source menu Refactor and Reformat actions with review, formatter profiles, and rollback expectations.
- UML Modeling, Local Bug Repository, Report Center, Project Documentation, deployment documentation, flowcharts, ERD documentation, and local-only bug import/export.

## Embedded Project About And Help Rule

Every project created by mEditor must carry this embedded documentation model:

- **About menu:** `Help > About Project`
- **Help menu:** `Help > Project Help`
- **Documentation folder:** `.meditor/project/docs`
- **About file:** `.meditor/project/docs/about.md`
- **Help index:** `.meditor/project/docs/help-index.md`
- **Help topics:** `.meditor/project/docs/help-topics.toml`
- **Window behavior:** same-window tab by default
- **User rule:** documentation is generated by mEditor and remains editable by the user

## Baseline Rules

- Product spelling must remain exactly `mEditor`.
